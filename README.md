# csm3-cg-verify


**For Summon Night - Craft Sword Monogatari Hajimari no Ishi**

Help with verify modded cg of before import

### **Run**:
    python -m csm3cgv

When installing python make sure you tick the box that says to add Python to PATH or include python in PATH etc

After you do that simply run install.bat when that finishes run launch .bat

If you use Linux IDK figure it out on your own lol

### **Dependency**:
`PyQt5, numpy, pillow`

### **Tips**:
+ Click into image will show pixel coordinate
+ Image can be view with different palette if click override
